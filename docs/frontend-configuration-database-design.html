03테이블·컬럼 사전

PK 기본키·복합키 구성FK 외래키선택 = NULL 허용
16개 테이블
ID와 프로젝트 경계

프론트 ID는 text 유지. 프로젝트 내부 참조는 (project_id, id) 복합 FK.

타입·시각

API의 bigint는 10진 문자열. 생성/수정 시각은 timestamptz. 공통 시각 컬럼도 표에 포함.

좌표·단위

장면은 m · 오른손 · +Y 위쪽. 회전은 Euler XYZ rad. 센서 pose는 quaternion 변환.

파일·버전

파일 바이트는 외부 저장소. 배치는 고정 버전 참조. READY 자산·저장본 본문은 불변.

04저장 절차·협의 사항

구성 저장 → 뷰어 배포

  1. 파일 업로드·검증 → asset version을 READY로 확정
  2. 구성 저장 → lock_version 검사 + request_id 중복 방지
  3. 한 트랜잭션 → 원장·revision·자산 참조·saved 포인터 확정
  4. 배포 → 검증된 revision으로 published 포인터 변경
  5. 뷰어 조회 → 배포 구성 + 별도의 실측 API/SSE

구현 전에 합의할 4가지

3D ROI ↔ 2D 영상 ROI
설비 로컬 m와 영상 0–1 좌표를 분리. 3D 집계 지원 여부 확인.
모델 좌표·로더
OBJ/PLY와 glTF 지원, 원본 단위·축·정합 변환을 동일 계약으로 처리.
지표·경고 의미
변화율 %와 change_score, DANGER 등급, 지속 시간과 N-of-M의 변환 확정.
삭제·복원
배포·복원본이 참조한 파일은 보존. DB와 파일 저장소를 함께 백업.
