# 설비 기준좌표 계약

## 설정

설비 상세 2단계에서 모델 방향·실제 크기·정렬을 맞춘 뒤 기준좌표를 적용한다.
기본 원점은 지정한 정면의 좌측 하단이다. 스캔만 사용하는 경우 정렬된 스캔의 외곽,
캐비넷 도형을 함께 쓰는 경우 도형의 고정 치수를 기준으로 산출한다.
정면은 +Z / +X / −Z / −X 또는 Y축 회전각으로 지정한다. 원점은 모델 좌표 입력 또는 표면 클릭으로 변경할 수 있다.

- 단위: m. 오른손 좌표계. +X 오른쪽, +Y 위, +Z 정면 바깥쪽. 내부 방향은 −Z.
- `equipment.metadata.coordinateFrame`에 저장하며 프로젝트 저장·복원 대상이다.
- 원점은 적용 시 고정된다. 문 열림, 표시 도형 전환, 월드 배치 변경에 따라 재계산하지 않는다.
- 기준 변경 시 센서·ROI의 실제 위치는 유지한다. 기준 버전이 바뀌면 센서 보정을 다시 확인·전송한다.
- 모델 자체의 정렬·치수를 바꾸는 작업은 기준 변경과 다르다. 센서·ROI 부착 위치를 다시 확인해야 한다.

## 기준 정보

```json
{
  "id": "equipment-frame:E1",
  "equipmentId": "E1",
  "version": 1,
  "unit": "m",
  "handedness": "RIGHT",
  "up": "+Y",
  "front": "+Z",
  "origin": [-0.5, 0, 0.3],
  "rotation": [0, 0, 0],
  "originMode": "FRONT_LOWER_LEFT"
}
```

`origin`은 모델 내부 좌표에서의 원점이며 `rotation`은 기준축 → 모델축 회전(rad, Euler XYZ)이다.
편집기 내부의 모델 좌표는 기존 위치 보존을 위해 유지한다. 화면 좌표 입력과 API 경계에서 변환한다.

`기준 좌표 = R⁻¹ × (모델 좌표 − origin)`

`모델 좌표 = R × 기준 좌표 + origin`

월드 표시는 위 모델 좌표에 기존 설비 배치 변환을 적용한다. ROI 반지름, 삼각형 인덱스, 빈 표면 제외 마스크는 기준 변환으로 바뀌지 않는다.

## 센서·ROI 전송

- 기준이 설정된 센서 보정과 ROI 요청은 `schemaVersion: 2`와 전체 `coordinateFrame`을 포함한다.
- 센서 `pose.space: EQUIPMENT_LOCAL`의 위치·회전은 새 기준 좌표계 값이다. 외부 월드 설치 센서도 전송 시 해당 설비 기준으로 변환한다.
- `equipmentTransform`은 기존 모델 루트의 월드 배치이다. `surfaceMount`의 부착면/u/v와 모델 경로는 기존 도형의 부착 정보다. 이를 기준좌표 XYZ로 해석하지 않는다.
- ROI `surface.coordinateSpace: EQUIPMENT_LOCAL`의 `center` 또는 모든 `vertices`를 같은 기준으로 변환한다.
- ROI 저장·미리보기, ROI 음원 선택, 표면 지점 음원 선택에 동일한 기준을 사용한다.
- 서버 ROI 저장 응답 및 목록은 해당 ROI를 저장한 **전체 기준 정보**를 돌려준다. 프론트는 이를 역변환해 기존 모델 위치에 표시한다. 기준 누락 저장 응답은 오류 처리한다.
- 기존 기준 미설정 프로젝트는 v1 모델 좌표를 유지한다. v1과 v2의 `EQUIPMENT_LOCAL`을 기준 정보 없이 혼용하지 않는다.

## 분석 결과 수신

좌표 기반 결과는 `equipmentId`, `position: [x,y,z]`, `coordinateFrame: {id, version}`을 포함한다.
핫스팟은 기존 `modelVersion`, `representation`, `measuredAt`, `quality` 정보도 유지한다.
현재 설비와 기준 ID·버전이 일치할 때만 위치를 역변환한다. 기준 정보 누락 또는 버전 불일치는 표시하지 않고 오류를 안내한다.
UV 열화상·비전 텍스처는 기존 UV 매핑 계약을 유지한다. 신호 발생 위치와 강도 계산은 백엔드 담당이다.

프론트 직렬화·역변환을 구현한 계약이며, 실제 서버의 v2 수용·저장·응답 처리는 별도 연동 확인이 필요하다. DB 마이그레이션은 포함하지 않는다.
